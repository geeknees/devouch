# Roadmap

The maintained application provides contributor endorsement publication, withdrawal, local verification, a static workspace, and a read-only GitHub Action. See the [protocol](protocol.md) for supported behavior and [history](history.md) for dated verification evidence.

The ERC-8004 evaluation in [Issue #25](https://github.com/geeknees/devouch/issues/25), [migration](upgrading-0.3.md), and hosted ERC workspace rollout are complete. The [rollout record](history.md) covers deployed file equality and wallet-free PR verification. Public-chain feedback publication/withdrawal by a real wallet and accepted public contributor evidence remain release acceptance work. Public registry reads, local EVM tests, and hosted missing-evidence reports are separate evidence.

Independent third-party adoption remains an open milestone. The recorded real Action trial was in this project's own repository; it is not independent adoption evidence.

World ID remains deferred. There is no planned central Devouch service, custom endorsement contract, global score, token incentive, or automatic PR approval/merge. See [design principles](design.md) for the reasons and integration conditions.
