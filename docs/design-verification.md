- ヘッダーの太陽／月ボタンで切り替える。初期表示は既存のダークで、ライトはアイボリーの背景と深い緑の文字・操作を使う。
- 選択をブラウザ内に保存し、再読み込みの描画前に同梱 `theme.js` で復元する。ローカル配信のCSPを維持し、外部スクリプト・フォントを追加しない。
- Enter／Spaceによる操作、保存の読み書きが拒否された場合、未対応の保存値を確認した。ウォレット待機中も切り替えられ、レビュー・同意・入力の固定を維持する。
- 新規ブラウザ7ケースが成功。既存テストと合わせ、Ruby 19 tests / 113 assertions、TypeScript単体25 tests / 74 assertions、結合22 tests / 176 Bun assertionsが成功した。結合テストには追加のPlaywright検査も含む。
- 型検査・Ruby構文検査・buildが成功。保存済みライトの初期描画は、`app.js` の到着を遅らせた実ブラウザで確認した。
- 両モードで320 / 390 / 600 / 768 / 1024 / 1440pxの全4タブ、計48通りに横溢れなし。主要な本文・補足・状態表示・主ボタンの色は4.5:1以上のコントラストを確認した。
- 追加の目視確認では360 / 440 / 601 / 640 / 680 / 850pxも含む12幅を測定し、横溢れ・ブラウザエラーなし。1440 / 390 / 320pxの両配色を撮影して確認した。

## 実装

- 深い緑の背景、ライムの主操作、セリフ体の見出しを発表資料に合わせた。
- Instrument Serif、IBM Plex Sans、IBM Plex Mono の6フェイスを5つのWOFF2に同梱した。Sansの400/500は同じ可変フォントを使う。
- 出典・チェックサム・OFLを [web/fonts/](../web/fonts/README.md) に保存し、配布物にも完全なライセンス文を含めた。実行時の外部フォント取得はない。
- ヘッダーに既存ロゴと同じ図形のインラインSVG、README冒頭に元SVGへの参照を追加した。ロゴとカバーの元データは変更していない。
- 確認中・取得不可はdim、成功はlime、失敗・失効はemberで表示する。既存の説明文と署名・公開・失効の個別確認は維持した。
- 小さい本文になるLABと入力ヒントにはfaintではなくdimを使った。faintは装飾の罫線と補助的なタブ番号に限定する。
- 任意の背景アニメーションは追加していない。
